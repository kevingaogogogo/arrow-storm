GAME DESIGN REVIEW · 策划对标

《箭雨》距离《弓箭传说》还差什么？

以 Habby《弓箭传说》(Archero) 的策划标准审视《箭雨》——它已经跑通了「自动飞行 + 穿门升级 + 御剑 + Boss」的核心循环， 但停留在「单局爽感」层面。真正的差距不在画面，而在 成长系统的纵深 和 长线留存结构。
核心结论
当前《箭雨》≈ 弓箭传说的 1/10 体量：单局 5 分钟可玩，但缺少「局外成长」「技能构筑乘区」「关卡目标感」三大支柱。 建议按 P0 构筑深度 → P1 局外成长 → P2 内容生态 三步走，每步都能独立提升可玩性。
1八大维度对标 当前状态 vs 弓箭传说标准
维度当前《箭雨》弓箭传说标准差距
局内成长 穿门二选一，12 种升级，线性叠加（+12% 这类） 清房后三选一，100+ 技能分四大派系（弹道/元素/召唤/辅助），构筑流派成型 核心缺口
构筑乘区 伤害/攻速/穿透各自独立，无明显联动化学反应 攻速×多箭×穿透×暴击×元素 形成乘区，后期 5 万箭/秒的成装爽感 核心缺口
局外成长 仅最高分记录（localStorage 一个数字） 金币 + 装备五槽（弓/衣/戒/护符/宠物）+ 英雄系统 + 天赋树，死亡后变强 核心缺口
关卡结构 无尽距离 + 每 5 波 Boss，无终点无目标 章节制（50 章×50 关），每章 Boss，通关目标 + 失败重试，扫荡系统 中
操作维度 只控制左右横移，自动射击，操作深度 1 维 四方向走位躲弹幕 + 主动瞄准射击（拖拽蓄力），操作即乐趣 中
打击反馈 已有伤害数字/粒子/震屏/升级演出（v2.0 刚加） 命中顿帧 + 分层音效 + 受击高亮 + 击杀慢镜，每击有"重量" 中

内容生态 无金币、无任务、无排行、无每日 每日挑战 + 签到 + 赛季排行 + 活动关卡，每天回来玩 10 分钟的理由 核心缺口

P0 · 1-2 天

构筑深度改造

单文件内可完成，直接翻倍重玩性
  • 升级改三选一：穿门改为暂停三卡，卡片带图标+稀有度（白/蓝/紫/金）
  • 引入乘区联动：攻速×多箭×穿透互乘，元素箭可叠加双属性
  • 流派标签：连选 3 个同系技能触发"流派觉醒"加成
  • 稀有度权重：金色技能（如"每次命中+1箭"）低概率高价值
P1 · 3-5 天

局外成长系统

让"死"变得有价值，留存的核心引擎
  • 金币经济：击杀/宝箱掉金币，死亡结算入账
  • 三件装备槽：弓（伤害/射速）、护符（暴击/穿透）、法阵（元素），每件 3 级
  • 永久天赋：初始 +10% 伤害 / +1 生命 / 开局多一箭，金币购买
  • 关卡目标：章节制，通关第 5/10/15 波 Boss 解锁下一章
P2 · 后续

内容生态

从"游戏"变成"每天想打开的玩具"
  • 每日挑战：固定种子+特殊规则，排行榜晒分
  • 英雄系统：3 个角色差异化技能（速射/暴击/御剑大师）
  • Boss 图鉴：击杀解锁图鉴条目，集齐奖励
  • 双周活动：限时事件关（全屏弹幕/无限御剑）
评估基准：《弓箭传说》(Archero, Habby) 全球爆款竖屏 Roguelite 的标准架构。差距评级基于当前代码结构（单 HTML 文件，~47KB）的改造可行性。 P0 全部可在现有单文件内实现；P1 建议拆分为多文件或保持单文件但扩大至 80-100KB；P2 需要后端（排行/每日种子）。 数据为策划经验评估，非实际运营数据。
